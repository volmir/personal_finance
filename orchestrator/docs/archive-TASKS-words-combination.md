# Составь слова · очередь рефакторинга кампании

36 задач в порядке выполнения. Файл предназначен для `orchestrator/TASKS.md` из архива проекта. У каждой задачи есть отдельный промпт, проверяемый результат и `tier`. Ссылки на предшественников находятся внутри промптов. Обычный запуск идёт сверху вниз, а режимы `--only` и `--from` сами зависимости не проверяют.

| Приоритет | Задачи | Результат |
|---|---|---|
| 1 | SPEC, FREQ, CORE-01…03, HINT | Закреплены решения, доступен источник частот, определены правила игры и подсказок |
| 2 | LEX, BLOOM, CORE-04, GEN | Автоматический отбор слов, назначение целей, проверка достижимости и сложности |
| 3 | SAVE, APP, UI | Совместимые сохранения, карта, экран уровня, подсказки и навигация |
| 4 | PIPE, QA, DATA, DOC, PACK | Воспроизводимая сборка, сквозные проверки, реальный набор и переключение APK |

| Tier | Модель по config.json | Уровень размышления |
|---|---|---|
| light | `gpt-5.6-luna` | low |
| standard | `gpt-6.1-sol` | medium |
| heavy | `gpt-6-astra` | high |

Парсер получает модель и усилие из `config.json` по полю `tier`. Эти назначения относятся к исполнителю промпта. Модель, которая категорирует слова при подготовке контента, настраивается отдельно.

### Два решения для игры

**Постоянный возврат к пройденным уровням совместим с кампанией.** Порог R отвечает за продвижение вперёд. Остальные звёзды можно добрать сразу, через несколько уровней или после финала. «Продолжить» до финала ведёт к ближайшему ещё не пройденному уровню. Если игрок хочет вернуться, он выбирает карточку сам. Финал — 4 звезды на 30-м уровне, «Мастер» — все 100 звёзд.

**У длинного слова T3 различаются назначенная цель подсказки и фактический ответ.** Генератор резервирует одну уникальную цель, а игрок получает звезду за любое подходящее слово. Иначе надпись «найдите слово из L или более букв» обещала бы более широкий зачёт, чем даёт игра. Эта же логика отделяет три нежелательных слова-разгадки от обычного словарного ввода.

### Откуда взять частотность

В закреплённом русском `ru_full.txt` каждая строка содержит словоформу и число употреблений в субтитрах OpenSubtitles 2018. Проверенный файл содержит **1 423 050 строк, 28 999 417 байт**. SHA-256 совпадает с `data/manifest.json → selection.frequency_source.sha256`. Задача FREQ-01 добавляет загрузку в стандартный кэш по одной команде `python3 tools/prepare_frequency.py --allow-network`. Собственный файл или путь от владельца игры не требуются. [Скачать закреплённый ru_full.txt](https://raw.githubusercontent.com/hermitdave/FrequencyWords/f8a65e6ddc17e0baa2e366a909986798d8dbe55b/content/2018/ru/ru_full.txt) · [Описание и условия именно этой ревизии](https://github.com/hermitdave/FrequencyWords/blob/f8a65e6ddc17e0baa2e366a909986798d8dbe55b/README.md)

Для независимой проверки спорного слова подойдёт частотный словарь Ляшевской и Шарова на материалах НКРЯ. В основе художественные, газетные, технические и другие тексты, а также устная речь. Частоту по лемме можно сопоставить с рангом игры; абсолютные числа двух корпусов по разным шкалам складывать нельзя. Воспроизводимая сборка использует один закреплённый источник. [Описание словаря НКРЯ](https://philology.hse.ru/russian_dict)

### Запуск из корня проекта

Поместите этот файл в `orchestrator/TASKS.md` и сохраните изменение коммитом. Для новой пачки с прежним журналом примените штатную процедуру очистки из `orchestrator/README.md`. В архиве рабочая очередь пуста. Ключи и push задаются настройками самого оркестратора.

```bash
bash orchestrator/run.sh --dry-run
bash orchestrator/run.sh
```

Для выполнения gate нужны JDK 21, Android SDK 36 и настроенная debug-подпись (в архиве сборка использует проектный `debug.keystore` через Gradle). `--dry-run` этих зависимостей не требует. По правилам проекта каждая задача проходит `--check full`; профиль `android` добавляет компиляцию инструментальных тестов и lint. Разработка инструментов идёт на фикстурах. Полный снимок Kaikki нужен для DATA-01, точный хэш указан в промпте. Перед длительной обработкой реального корпуса учтите настроенный `task_timeout` в 3600 секунд; промежуточный кэш допускает возобновление.

**Граница последней задачи.** Ручное утверждение списков слов исключено. У оркестратора есть отдельное проектное требование для изменения Gradle — успешная `:app:assembleRelease`. В поставленном архиве текущая БД имеет `audit.passed=false` и временную `rights_policy=wiktionary-provisional-v1`. Поэтому переключение Gradle поставлено в PACK-01 в конце: разработка, тесты и проверка реального кандидата могут пройти раньше. С этой БД ожидается остановка последнего gate. Это фиксируется отдельно от результата debug и от готовности содержания кампании.
