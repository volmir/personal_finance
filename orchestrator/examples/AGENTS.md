# Пример правил для целевого проекта

Адаптируйте этот файл и объедините с существующим AGENTS.md своего проекта.

- Выполняйте только переданное задание, без постороннего рефакторинга.
- Выбирайте простое решение с минимальным количеством зависимостей.
- Сохраняйте публичный API, если задача явно не требует его изменить.
- Проверяйте затронутое поведение и честно указывайте, что не проверено.
- Не ослабляйте проверки ради зелёного результата.
- Не выполняйте Git-коммиты и push: ими управляет внешний оркестратор.
