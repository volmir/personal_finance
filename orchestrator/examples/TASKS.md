# Примеры задач (не входят в рабочую очередь)

Перенесите согласованную секцию в рабочую очередь `orchestrator/TASKS.md`
и подставьте команды gate вашего проекта (см. `orchestrator/examples/
config.example.json`, ключ `checks`).

## DOC-1: Уточнить инструкцию локальной сборки
tier: light
gate: bash orchestrator/run.sh --check full
retries: 1
```prompt
Проверь раздел о сборке и запуске в README.md по текущим конфигурационным
файлам проекта и AGENTS.md. Уточни команды только при обнаружении
расхождений. Не устанавливай SDK и JDK, не меняй зависимости, данные,
конфигурацию сборки и правила проекта. В отчёте перечисли исправления
либо объясни, почему они не нужны.
Не выполняй коммит и push: ими управляет оркестратор.
```
