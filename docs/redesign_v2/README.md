## Приоритет источников истины

1. Формулы, пороги, статусные цвета и реальные результаты — **действующий Kotlin-код**, `FinancialMetricEvaluator`, `StatusColors`, `ScoreColorEvaluator`, `Formatters`.
2. Поведение и информационная архитектура — `UIUX_V2_SPEC.md` + утверждённые уточнения из `AGENTS.md`.
3. Макеты — визуальный референс расположения, плотности и иерархии, **не** источник числовых значений, статусов и точных названий всех сценариев.

**Важная цветовая корректировка:** на некоторых демонстрационных макетах гейдж с баллом 6,7 окрашен зелёным; это визуальная неточность макета. По действующему `ScoreColorEvaluator` 6,7 — **нейтральный жёлтый**. Для всех позитивных/нейтральных/негативных показателей соблюдать статусную систему и контраст для светлой/тёмной темы. Нельзя механически копировать цвет макета при противоречии фактическому статусу.

**Важная контентная корректировка:** макет раскрытых событий содержит строку «Другой сценарий» как условный заполнитель; в приложении её **не должно быть**. Показывать все 14 реальных сценариев в 2 группах по 7 согласно `FireScenarioToggles`. Демонстрационные цифры и целевой капитал на PNG не являются эталонными расчётами.

Перед реализацией любой задачи прочитать соответствующий раздел спецификации и связанные макеты. Сохранять три основные вкладки, навигацию Back, все существующие поля, 6 языков, 3 экспорта и рассчитанные значения. Если макет противоречит числам, цветам или функциональности действующего приложения — доменные источники истины имеют приоритет; расхождение указать в отчёте.
