# Feedback / Обратная связь

Спасибо, что помогаете развивать **Финансы и FIRE**!

- **Вопросы, идеи и обсуждения:** [GitHub Discussions](https://github.com/volmir/personal_finance/discussions).
- **Воспроизводимые ошибки:** [GitHub Issues](https://github.com/volmir/personal_finance/issues/new/choose).
- **Видеообзор:** [YouTube](https://www.youtube.com/watch?v=BnHzJTz49Uo).
- **APK:** [GitHub Releases](https://github.com/volmir/personal_finance/releases).

## Как выбрать раздел

| Что хотите сообщить | Куда обращаться |
| --- | --- |
| Не знаете, как пользоваться функцией | Discussions → Q&A |
| Хотите предложить новую функцию | Discussions → Ideas |
| Обсудить FIRE, формулы или методику | Discussions → General |
| Нашли сбой или неправильный результат | Issues → Bug report / Calculation error |
| Обнаружили неудобство или дефект интерфейса | Issues → UI/UX issue |

Для ошибок укажите версию приложения, устройство, версию Android, действия для воспроизведения, ожидаемый и фактический результат.

**Конфиденциальность:** не публикуйте реальные данные о доходах, банковских счетах, активах и долгах. Для примеров используйте вымышленные значения.

# Feedback (English)

Questions, feature ideas, and discussions belong in [GitHub Discussions](https://github.com/volmir/personal_finance/discussions). Reproducible bugs, calculation errors, and UI problems belong in [GitHub Issues](https://github.com/volmir/personal_finance/issues/new/choose).

Please include the app version, Android version, device, steps to reproduce, expected behavior, and actual behavior. **Use fictional financial values and remove private information from screenshots and logs.**
