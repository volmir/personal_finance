# Публикация приложения в репозитории IzzyOnDroid (F-Droid)

## Как устроен IzzyOnDroid
В отличие от официального F-Droid (который сам компилирует проект из исходного кода), **IzzyOnDroid** — это автоматизированный репозиторий:
1. Вы создаете открытый репозиторий на **GitHub** (или GitLab/Codeberg).
2. Вы публикуете релиз (**GitHub Release**) и прикрепляете к нему готовый `.apk` файл (или это делает автоматически добавленный нами скрипт GitHub Actions при установке тега `v1.0.0`).
3. Робот IzzyOnDroid регулярно проверяет ваши релизы на GitHub, скачивает APK, проверяет его сигнатуру и метаданные и доставляет обновление пользователям через каталог F-Droid.

- ✅ **Автоматическая сборка релизов в GitHub Actions**: настроен workflow `.github/workflows/build-and-release.yml`.

## Пошаговая инструкция для публикации:

### Шаг 1. Экспорт репозитория на GitHub из AI Studio
1. В верхнем правом углу Google AI Studio нажмите на меню проекта (три точки или иконка экспорта) → выберите **«Export to GitHub»** / **«Push to GitHub»**.
2. Укажите имя репозитория (например, `personal-finance-fire`) и сделайте репозиторий **Public** (публичным).

### Шаг 2. Создание первого релиза (Release v1.0.0)
Есть два способа:

**Вариант А (Автоматический через GitHub Actions):**
1. В вашем репозитории на GitHub перейдите во вкладку **Releases** → **Draft a new release**.
2. В поле тега введите `v1.0.0`, нажмите «Create new tag: v1.0.0 on publish».
3. Заполните название («Release 1.0.0») и нажмите **Publish release**.
4. GitHub Actions автоматически запустит `.github/workflows/build-and-release.yml`, соберет APK и прикрепит файл `PersonalFinance-v1.0.0.apk` к этому релизу!

**Вариант Б (Ручной):**
1. В AI Studio скачайте скомпилированный APK (меню «Download APK» или из директории `.build-outputs`).
2. В GitHub перейдите в **Releases** → **Draft a new release** → создайте тег `v1.0.0` и перетащите мышкой скачанный `.apk` файл в блок «Attach binaries by dropping them here».
3. Нажмите **Publish release**.

---

### Шаг 3. Подача заявки в каталог IzzyOnDroid
1. Перейдите в официальный трекер заявок IzzyOnDroid:  
   👉 **https://gitlab.com/IzzyOnDroid/repo/-/issues**
2. Нажмите кнопку **«New issue»**.
3. В выпадающем списке шаблонов («Template») выберите: **`inclusion-request`** (Запрос на включение приложения).
4. Заполните поля шаблона:
   - **App Name**: `Personal Finance & FIRE` (Личные финансы)
   - **Repository URL**: ссылка на ваш репозиторий GitHub (например, `https://github.com/<ваш-логин>/personal-finance-fire`)
   - **License**: `MIT`
   - **APK source**: `GitHub Releases`
5. Отправьте тикет. Модератор IzzyOnDroid (Izzy) обычно проверяет и добавляет приложение в течение 1–3 дней.
6. После добавления любое создание нового релиза с тегом (например, `v1.0.1`) будет автоматически подхватываться IzzyOnDroid без необходимости повторной подачи заявки!
